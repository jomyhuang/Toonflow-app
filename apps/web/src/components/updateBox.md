### 新增

- 首页和 Agent 对话新增语音输入，支持按住说话或点击录入；需浏览器或系统支持语音识别，并允许使用麦克风。
- 音频和音频生成节点新增「转文本」，识别结果自动生成文本节点；仅在支持音频轨道识别的桌面浏览器中可用，并依赖可用的语音识别服务。
- 新增「逐帧拉片」节点，可从视频中提取分镜关键帧、镜头片段和原音轨，自动生成素材节点，并支持查看报告和下载清单。可选用支持图片理解的模型，生成逐镜头说明和整段分析。
- 插件市场新增 MCP 工具接入，支持添加本地或远程服务、导入 JSON 配置和 DXT/MCPB 扩展包，并提供连接测试、工具查看和启停管理；本地服务需桌面端或服务器支持。

### 优化

- 首页焕新，支持折叠侧栏和显示项目封面，常用入口更集中；打开项目时增加加载提示。
- 首页可直接打开全局素材库，支持卡片浏览、类型筛选、目录导航和音视频预览。
- 思考强度根据所选模型显示可用档位，支持自定义模型的档位配置，并在刷新模型列表时保留相关设置。
- 优化 Agent 的 Token 用量、生成速度和上下文占用展示，回复过程中及时更新，压缩上下文后继续显示估算结果。
- 优化图片、视频和音频并行生成时的状态查询，减少长任务的连接占用，并容忍短暂网络波动。
- 调整画布工具栏和面板布局，减少控件占用，并在工具栏增加节点搜索入口，方便快速定位节点。
- 启动时优先使用已有模型列表，远程刷新在后台进行，减少网络等待对启动的影响。
- macOS 安装镜像增加拖拽安装引导，方便将应用放入「应用程序」目录。

### 修复

- 修复鼠标侧键意外触发历史导航、退出工作区的问题。
- 修复 macOS 使用实体 Ctrl 键配合滚轮缩放时，画布缩放步长异常增大的问题。
- 修复 Linux 点击鼠标中键时，系统剪贴板文本被意外粘贴到画布的问题。
- 修复 Windows 安装时，将带通道后缀的 WebView2 版本误判为不可用的问题。
- 修复 Windows 桌面通信端口冲突可能导致启动失败的问题。
- 修复桌面端部分外部链接未通过默认浏览器打开，以及 Windows 使用 Ctrl 刷新时误开浏览器的问题。
- 修复切换项目时旧文档状态未及时释放的问题，避免干扰新项目的文档打开与保存。
- 修复 Agent 在工具执行或等待用户输入后，可能因复用失效连接而请求失败的问题。
